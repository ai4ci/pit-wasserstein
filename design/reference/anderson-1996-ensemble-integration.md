Produces probabilistic forecasts from ensemble model integrations by combining members of the ensemble. Provides a framework for evaluating the performance of such probabilistic forecasts. The method produces ensemble-like outputs from individual model runs, allowing probabilistic prediction from deterministic models.

**Why cite:** Ensemble forecast methodology and evaluation framework that underpins the use of ensemble members as probabilistic predictive distributions.
