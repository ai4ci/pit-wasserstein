Pre-existing. `tests/testthat/test-unit-scoring.R` is generated by `pkgtools`
from `@unit` roxygen tags and starts with:

```r
library(pit-wasserstein)
```

`pit-wasserstein` is not a valid R identifier (unquoted hyphen), so this is a
syntax error — the generated file cannot even be sourced, let alone pass.
`DESCRIPTION`'s `Package:` field is `pitw`, not `pit-wasserstein`, so this
predates the package rename and the generator has not been re-run since.

Likely affects every file matching `tests/testthat/test-unit-*.R` generated
the same way, not only this one — worth checking all of them once fixed.

Suggested fix: re-run `devtools::document()` (or the `pkgtools` roclet
directly) now that `DESCRIPTION` names the package `pitw`, which should
regenerate these files with the correct `library(pitw)` call. Confirm with
`devtools::test()` afterwards.
