# A log1p y scale

A log1p y scale

## Usage

``` r
.gg_scale_y_log1p(..., n = 5, base = 10, sf = 2)
```

## Arguments

- n:

  the number of major breaks (default `` `5` `` \[numeric\])

- base:

  the base for the logarithm (default `` `10` `` \[numeric\])

- sf:

  significant figures (default `` `2` `` \[numeric\])

## Value

a ggplot scale
