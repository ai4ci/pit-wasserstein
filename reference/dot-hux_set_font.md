# Set the font family and size in a huxtable globally

Set the font family and size in a huxtable globally

## Usage

``` r
.hux_set_font(hux, defaultFontSize = 8, defaultFont = "Roboto")
```

## Arguments

- hux:

  a huxtable table

- defaultFontSize:

  the desired font size (default `` `8` `` \[numeric\])

- defaultFont:

  the desired font (default `` `Roboto` `` \[character\])

## Value

the altered huxtable
